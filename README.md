# 대법원 전자소송 CAPTCHA 자동 인식 프로그램

## 개요
이 프로그램은 대한민국 대법원 전자소송 포털에 접속할 때 나타나는 보안문자(CAPTCHA)를 자동으로 인식하고 추출하는 자동화 도구입니다. 
법원 전자소송 사이트의 보안문자가 항상 **'6자리 숫자'**로 구성되어 있다는 특징을 활용하여, 노이즈가 심한 캡챠 이미지에서도 빠르고 정확하게 숫자를 판독할 수 있도록 구현되었습니다.

### 주요 특징
- **강력한 OCR 엔진**: 노이즈 및 두꺼운 선이 포함된 이미지 환경에서 숫자 인식률이 뛰어난 `ddddocr` 라이브러리 모델을 사용합니다.
- **이미지 전처리**: 이미지 크기를 2배로 확장하여 OCR 엔진의 특징 추출 능력을 극대화합니다.
- **자동 재시도 로직**: 판독된 텍스트에서 숫자를 추출한 결과가 정확히 6자리가 아닐 경우, 즉시 페이지를 새로고침하여 새로운 캡챠 이미지로 최대 10회까지 재시도를 수행합니다.
- **다양한 실행 환경**: 터미널 기반의 CLI 스크립트와 사용자 친화적인 GUI 애플리케이션 두 가지 버전을 제공합니다.

---

## 파일 구성
- `captcha_solver.py`: 커맨드 라인(CLI) 환경에서 동작하는 핵심 캡챠 인식 스크립트입니다. `Selenium`을 이용해 브라우저를 제어합니다.
- `ui_app.py`: `customtkinter`를 기반으로 제작된 데스크톱 GUI 애플리케이션으로, 진행 과정의 로그와 추출된 캡챠 이미지를 실시간으로 모니터링할 수 있습니다.
- `requirements.txt`: 프로그램 구동에 필요한 Python 외부 패키지들의 목록입니다.

## 실행 방법

### 1. 가상환경 세팅 (권장)
시스템 패키지와의 충돌을 방지하기 위해 가상환경 내에서 실행하는 것을 권장합니다.

```bash
# 가상환경(venv) 생성
python3 -m venv venv

# 가상환경 활성화 (macOS / Linux)
source venv/bin/activate

# 가상환경 활성화 (Windows)
# venv\Scripts\activate
```

### 2. 의존성 라이브러리 설치
가상환경이 활성화된 상태에서, 필수 패키지들을 설치합니다.

```bash
pip install -r requirements.txt
```
*(주의: `ddddocr` 등의 라이브러리가 존재하므로 Python 버전에 유의하시기 바랍니다. 오류 발생 시 Python 3.8 ~ 3.10 버전을 권장합니다.)*

### 3. 프로그램 실행

#### A. CLI 스크립트로 실행하기
터미널에서 직접 실행하며, 성공 시 `solved_captcha.png` 이름으로 원본 이미지가 저장됩니다.

```bash
python captcha_solver.py
```

#### B. GUI 애플리케이션으로 실행하기
시각적인 UI 창이 나타나며, [자동화 시작] 버튼을 클릭하면 브라우저가 실행되고 캡챠 인식 과정이 화면에 표시됩니다.

```bash
python ui_app.py
```

## 윈도우용 실행 파일(.exe) 만들기
이 프로그램은 파이썬이 설치되지 않은 환경의 일반 사용자도 클릭만으로 사용할 수 있도록 `.exe` 파일로 빌드할 수 있습니다.
(`pyinstaller`를 이용하며, 윈도우 PC에서 다음 과정을 진행해야 합니다.)

1. **윈도우 PC에서 소스코드 폴더로 이동** 후 가상환경을 세팅하고 패키지를 설치합니다 (`pip install -r requirements.txt`).
2. 프로젝트 폴더 내에 포함된 **`build_windows.bat`** 파일을 더블클릭하여 실행하거나 터미널에서 실행합니다.
3. 빌드 과정이 자동으로 진행되며, 완료 후 **`dist/CaptchaSolver`** 폴더 안에 `CaptchaSolver.exe` 파일이 생성됩니다.
4. 해당 폴더 전체를 압축하여 사용자에게 배포하시면 됩니다.
